## Описание работы
В данной работе реализованы три сценария распределенных вычислений:
1. **Статистический анализ:** Использование `MPI_Scatterv` для работы с массивами, размер которых не кратен числу процессов.
2. **Метод Гаусса:** Реализация прямого хода с использованием `MPI_Bcast` для передачи ведущей строки всем узлам.
3. **Алгоритм Флойда-Уоршелла:** Анализ графов с использованием `MPI_Allgather` для синхронизации состояния матрицы смежности.

## Основные результаты
- При увеличении количества процессов (np) время выполнения уменьшается, однако после определенного порога (8-16 процессов) рост производительности замедляется из-за сетевых задержек.
- Использование коллективных операций (`Reduce`, `Allgather`) значительно упрощает код и работает быстрее, чем ручная пересылка сообщений через `Send/Recv`.
