# Practical Work №10: Performance Analysis and Optimization

## Overview
Данная работа посвящена профилированию параллельных программ. Мы исследовали CPU (OpenMP), GPU (CUDA) и распределенные системы (MPI).

## Results
1. **Task 1 (OpenMP):** Выявлено, что ускорение ограничено последовательной частью кода согласно закону Амдала. При 8 потоках эффективность падает из-за накладных расходов.
2. **Task 2 (CUDA):** Коалесцированный доступ к памяти оказался в 5-10 раз быстрее "плохого" доступа с шагом.
3. **Task 3 (Hybrid):** Использование `cudaMemcpyAsync` позволило скрыть задержки передачи данных за счет параллельной работы CPU.
4. **Task 4 (MPI):** Протестированы Strong Scaling (ускорение при росте ядер) и Weak Scaling (устойчивость при росте данных).

## Conclusion
Оптимизация — это не просто добавление ядер, а устранение узких мест (bottlenecks), таких как доступ к памяти и сетевые задержки.
