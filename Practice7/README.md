## Теоретическая часть
- **Редукция:** Операция объединения множества элементов в одно значение (сумма, min/max) Основная сложность в параллелизме — иерархическое суммирование результатов блоков.
- **Сканирование (Prefix Sum):** Вычисление накопленного результата для каждой позиции массива, используется в сортировках и сжатии данных
## Описание решения
1. **Задание 1 (Редукция):** Реализован алгоритм с использованием `extern __shared__` памяти. Нити блока суммируют элементы парами, сокращая количество активных нитей вдвое на каждом шаге.
2. **Задание 2 (Сканирование):** Реализован инклюзивный скан. [cite_start]Каждый поток на итерации `s` добавляет к своему значению элемент, стоящий на расстоянии `s` слева.
