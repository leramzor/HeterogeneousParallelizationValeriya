### Задание 3 (Assignment1.task3.cpp) — Параллельный min/max
**Что сделано:**

- Реализованы обе версии (последовательная и параллельная) в одном файле.
- Параллельная версия использует OpenMP: #pragma omp parallel for.
- Для min и max применён reduction(min:min_par) reduction(max:max_par) — каждый поток имеет свою копию переменных, в конце OpenMP объединяет результаты.

**Как работает:**
// Параллельный цикл: каждый поток обрабатывает свою часть массива
- #pragma omp parallel for reduction(min:min_par) reduction(max:max_par)
- for (int i = 0; i < SIZE; ++i) {
-    if (arr[i] < min_par) min_par = arr[i]; // Локальное обновление минимума в потоке
-    if (arr[i] > max_par) max_par = arr[i]; // Локальное обновление максимума в потоке
