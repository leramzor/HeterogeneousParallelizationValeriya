Ответы на контрольные вопросы практической работы №4

Чем отличаются типы памяти в CUDA и в каких случаях их использовать?
Глобальная: Доступна всем потокам, большая, но медленная. Использовать для больших данных (Лекция №4: основная память для входных данных).
Разделяемая: Быстрая, общая для блока. Для обмена внутри блока (Лекция №4: оптимизация редукции).
Локальная: Быстрая, для одного потока. Для временных переменных (Лекция №4: в циклах сортировки).

Как использование разделяемой памяти влияет на производительность?
Ускоряет обмен данными внутри блока (в 10–100 раз быстрее глобальной) — минимизирует задержки (Лекция №4: пример редукции).
Доступ и как его обеспечить?
Коалесцированный доступ — когда потоки читают последовательные адреса. Обеспечить: выравнивание данных, индексация по threadIdx (Лекция №4: оптимизация глобальной памяти).
Какие сложности возникают при работе с большим объемом данных на GPU?
Ограничение VRAM, задержки копирования CPU-GPU, некоалесцированный доступ (Лекция №4: минимизация глобальной памяти).
Почему важно минимизировать доступ к глобальной памяти?
Она медленная (высокая латентность) — приводит к простою потоков (Лекция №4: использование разделяемой/локальной для оптимизации).
Как использовать профилирование для анализа производительности CUDA-программ?
С помощью Nsight Compute или nvprof: анализ occupancy, памяти, ядер (Лекция №4: инструменты NVIDIA для поиска bottlenecks).
