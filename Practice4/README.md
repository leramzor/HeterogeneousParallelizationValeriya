## Краткое описание решения

Задание 1 — Оптимизация редукции суммы (part1_reduction.cu)
Сравниваются две реализации:

- Глобальная память — простое атомарное сложение всех элементов в одну глобальную переменную (atomicAdd)
- Разделяемая память + глобальная — каждый блок сначала выполняет быструю редукцию внутри блока в разделяемой памяти, затем только один атомарный atomicAdd на блок

Основные результаты (N = 1 000 000 элементов):

- Global memory time:    ~0.0076 сек
- Shared memory time:    ~0.00000317 сек
- Ускорение:             ~2400×

Вывод:
Использование разделяемой памяти позволяет радикально сократить количество медленных обращений к глобальной памяти и конфликтов при атомарных операциях.


Задание 2 — Оптимизация сортировки на GPU (part2_sort_optimization.cu)
Реализован подход:

- Разбиение большого массива на подмассивы размером 256 элементов (по количеству потоков в блоке)
- Каждый блок сначала загружает свой подмассив в локальную память потока
- Выполняется пузырьковая сортировка внутри локальной памяти каждого потока
- Отсортированные подмассивы копируются в разделяемую память

Основные результаты (N = 1 000 000 элементов):
- Время выполнения оптимизированной версии: ~0.0073 сек
