## Описание работы
Целью работы является распределение вычислительной нагрузки между CPU и GPU. 
- CPU использует **OpenMP** для параллельной обработки.
- GPU использует **CUDA** для массовых параллельных вычислений.
- Реализован гибридный сценарий одновременной работы обеих архитектур.

## Анализ производительности
1. **CPU (OpenMP):** Показывает стабильное время, эффективен при работе с кэшем.
2. **GPU (CUDA):** Сами вычисления мгновенны, но передача данных через PCI-E добавляет накладные расходы.
3. **Гибридный режим:** Позволяет скрыть накладные расходы. Пока GPU занят копированием/вычислением второй части массива, CPU уже обрабатывает первую.

## Выводы
- **Эффективность:** Гибридный подход эффективен при очень больших объемах данных (N > 10^7), когда время вычислений значительно превышает время передачи.
- **Факторы:** Скорость шины PCI Express является главным ограничителем.
- **Оптимизация:** Передачу данных можно оптимизировать через асинхронные потоки (Streams) и использование `Pinned Memory`.
