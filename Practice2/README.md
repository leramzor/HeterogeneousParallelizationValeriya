## Описание задания

Практическая работа посвящена изучению параллельного программирования на CPU с использованием **OpenMP**.

**Основные цели:**
- Освоить параллелизацию простых алгоритмов сортировки O(n²)
- Реализовать последовательные и параллельные версии сортировок пузырьком, выбором и вставкой
- Провести сравнение производительности и проанализировать эффективность параллелизации

Работа основана на **Лекции №2: Архитектура CPU и многопоточность с использованием OpenMP**.
