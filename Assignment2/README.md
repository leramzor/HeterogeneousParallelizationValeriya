## Описание задания

Assignment 2 состоит из 4 задач, направленных на освоение **гетерогенной параллелизации** с использованием **OpenMP** (CPU) и **CUDA** (GPU).

- **Задача 1** — теоретическая (объяснение гетерогенной параллелизации).
- **Задача 2** — поиск min/max с OpenMP.
- **Задача 3** — параллельная сортировка выбором с OpenMP.
- **Задача 4** — параллельная сортировка слиянием на GPU (реализована как Bitonic Sort).

Работа основана на **Лекциях №1 (введение в гетерогенную параллелизацию), №2 (OpenMP и архитектура CPU) и №3 (архитектура GPU и CUDA)**.
