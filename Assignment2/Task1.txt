Задача 1. Теоретическое задание (25 баллов)
Гетерогенная параллелизация — это подход к параллельным вычислениям, при котором задачи распределяются между различными типами процессоров в одной системе, чаще всего между CPU и GPU (Лекция №1: Введение в гетерогенную параллелизацию и параллельное программирование).
Различия между параллельными вычислениями на CPU и GPU:

Архитектура CPU (Лекция №2): состоит из небольшого числа (4–16) мощных ядер с большим кэшем и сложной логикой ветвления. Оптимизирована для последовательного выполнения задач с высокой латентностью и сложными управляющими структурами.
Архитектура GPU (Лекция №3): содержит тысячи простых ядер, объединённых в блоки. Оптимизирована для массово-параллельного выполнения одинаковых операций над большими объёмами данных (SIMT — Single Instruction Multiple Threads). Имеет иерархию памяти (глобальная, разделяемая, локальная), где доступ к памяти критически влияет на производительность.

Преимущества гетерогенной параллелизации:

Максимальное использование ресурсов: CPU эффективно выполняет последовательные и управляющие задачи, GPU — массово-параллельные вычисления (Лекция №1).
Значительное ускорение для подходящих задач (обработка изображений, машинное обучение, научные симуляции).
Энергоэффективность: GPU даёт больше вычислительной мощности на ватт для параллельных задач.
Гибкость: позволяет адаптировать алгоритм под сильные стороны каждого устройства.

Примеры реальных приложений:

Машинное обучение и глубокие нейронные сети (TensorFlow, PyTorch): обучение моделей на GPU, инференс — часто на CPU/GPU.
Графическая обработка и рендеринг (игры, кино): GPU для рендеринга, CPU для физики и логики.
Научные симуляции (моделирование климата, молекулярная динамика): GPU для расчётов, CPU для управления.
Обработка видео и изображений (Adobe Premiere, Photoshop): GPU-ускорение фильтров и эффектов.
