## Подробное описание решения каждой части

### Часть 1 (`part1.cpp`) — Работа с массивами и параллельный min/max

**Что сделано:**
- Создан массив из 10 000 000 целых чисел.
- Массив заполнен случайными значениями от 1 до 100.
- Реализован последовательный алгоритм поиска минимума и максимума.
- Реализован параллельный алгоритм с использованием OpenMP.
- Для безопасного объединения результатов применён `reduction(min:...)` и `reduction(max:...)`.
- Время выполнения измерено с помощью `std::chrono`.
- Вычислено ускорение (speedup).

**Как работает:**
- Последовательная версия проходит массив одним циклом и обновляет min/max.
- Параллельная версия использует директиву OpenMP:

#pragma omp parallel for reduction(min:par_min) reduction(max:par_max)
for (int i = 0; i < N; ++i) {
    if (arr[i] < par_min) par_min = arr[i];
    if (arr[i] > par_max) par_max = arr[i];
}

Каждый поток работает со своей локальной копией переменных, после чего OpenMP объединяет результаты.

### Часть 3 (`part3y.cpp`) — Динамическая память и параллельное среднее

**Что сделано:**
- Массив из 10 000 000 элементов выделен динамически через new int[N]
- Заполнен случайными числами
- Реализованы последовательное и параллельное вычисление среднего значения
- В параллельной версии использована reduction(+:sum) для безопасного суммирования
- Память корректно освобождена через delete[] arr

**Как работает:**

// Параллельное суммирование с автоматическим объединением результатов
#pragma omp parallel for reduction(+:par_sum)
for (int i = 0; i < N; ++i) {
par_sum += arr[i];
}
double par_avg = par_sum / N;
